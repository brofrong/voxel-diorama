# Этап 3 «Атмосфера» — дизайн

Дата: 2026-10-07
Статус: согласован в чате, ожидает ревью спека
Базовые спеки: `2026-10-06-voxel-diorama-design.md`, `2026-10-06-stage-2-life-design.md`. В вопросах
этапа 3 главный — этот документ.

## 1. Цель

Диорамы получают живое время суток, небо на выбор, частицы, свет и качественную картинку, а зритель —
меню настроек во вьюере.

**Критерий успеха:**
- В меню (кнопка справа сверху) зритель меняет скорость смены дня и ночи (стоп · 0.5x · 1x · 1.5x · 2x),
  ползунком выставляет текущее время, выбирает небо (4 варианта) и качество — сцена откликается сразу.
- Демо «Зимняя ночь»: дым из труб, снег, костёр с искрами и мерцающим светом, фонари зажигаются в
  сумерках, окна светятся с bloom, звёздное небо.
- Скриншот карточки (`?capture`) по-прежнему детерминирован.
- «Тихая долина» выглядит как раньше.

### Решения, принятые в обсуждении

- Весь этап 3 — один спек и один план.
- Время суток — непрерывное (часы 0–24), солнце и свет считаются по часу.
- Частицы — без состояния на GPU (позиция = функция от времени и номера частицы, TSL).
- Время, скорость и небо из меню не запоминаются (замысел диорамы); качество, частицы и автоповорот —
  запоминаются в `localStorage`.

### Вне scope

- Тени от точечных источников света; столкновение частиц с крышами (только с землёй).
- Погодные сценарии (смена снега/дождя во времени), звук.
- Деплой — этап 4.

## 2. Время суток

### Модель

```ts
atmosphere: {
  time: { start: 21, speed: 0.5, cycle: 180 },
  // или time: { start: 'sunset' }, или старое time: { fixed: 'night' }
}
```

- `start` — час 0–24 или синоним: `dawn` = 6.5, `day` = 13, `sunset` = 18.5, `night` = 23. По умолчанию 13.
- `speed` — `0 | 0.5 | 1 | 1.5 | 2`, по умолчанию **0** (время стоит).
- `cycle` — длина суток в секундах при 1x, 30..3600, по умолчанию 120.
- Старая форма `{ fixed: X }` нормализуется в `{ start: X, speed: 0, cycle: 120 }`.
- `SceneConfig.time` = `{ start: number; speed: number; cycle: number }` (числа).

### Часы суток

- `hourAt(elapsed, { start, speed, cycle }) = (start + elapsed · speed · 24 / cycle) mod 24`, где
  `elapsed` — секунды часов анимации (идут только при рендере, на паузе стоят).
- `setHour(h)` перезапускает отсчёт: новый `start = h`, `elapsed` с нуля; `setTimeSpeed(x)` сохраняет
  текущий час и меняет скорость.
- В режиме `?capture` час всегда равен `start` (скорость игнорируется).

### Солнце, луна, ночной коэффициент

- Угол солнца `a = (hour − 6) / 12 · π`; направление «к солнцу» = `normalize([cos a, sin a, 0.35])`
  (восход с +x, полдень над головой с наклоном к +z, закат на −x). Луна — то же для `hour + 12`.
- Высота солнца `e = sin a`. Ночной коэффициент `night = 1 − smoothstep(−0.12, 0.12, e)` (0 днём, 1 ночью).
- Тень отбрасывает один направленный свет: солнце при `e > 0`, иначе луна (холодный, яркость 0.6);
  переход сглажен по `night`.
- Свечение материалов умножается на `uEmissiveScale = mix(0.3, 1.5, night)`.

### Палитра по часу

Опорные точки (значения — существующие пресеты `src/engine/atmosphere/presets.ts`):
`0 ночь · 5.5 ночь · 6.5 рассвет · 9 день · 17 день · 18.5 закат · 20 ночь · 24 ночь`.
Между точками линейно интерполируются: цвет и сила солнца, цвета и сила полусферного света, зенит,
горизонт, туман, экспозиция. Функция чистая: `paletteAt(hour): LightingPreset` (без направления солнца).

## 3. Небо

`atmosphere.sky: 'gradient' | 'solid' | 'realistic' | 'stylized' | { kind: 'solid', color: '#rrggbb' }`,
по умолчанию `'gradient'`. `SceneConfig.sky = { kind; color?: string }`.

| Вариант | Реализация |
|---|---|
| `gradient` | текущая сфера: горизонт → зенит, цвета `paletteAt(hour)` |
| `solid` | `scene.background` = `color` или горизонт по часу |
| `realistic` | `SkyMesh` (`three/addons/objects/SkyMesh.js`), позиция солнца по часу; ночью — затемнение до зенита ночной палитры + звёзды |
| `stylized` | градиент + диски солнца и луны (billboard-квадраты) + звёзды ночью (точки на сфере, видимость × `night`) + 8–12 воксельных облаков (кубики), медленно плывущих по кругу |

Все варианты детерминированы по `seed` диорамы и часам анимации. `setSky(kind)` переключает без
перезагрузки мира.

## 4. Меню настроек во вьюере

- Кнопка ⚙ «Настройки» справа сверху; панель открывается под ней; закрытие — кнопка, клик вне, Esc.
  До 600 px шириной — нижняя панель на всю ширину. В `?capture` кнопки нет.
- Содержимое:
  1. **Время суток** — `<input type="range" min=0 max=24 step=0.05>`, подпись `ЧЧ:ММ`. Перетаскивание
     вызывает `setHour`; без перетаскивания значение раз в 200 мс берётся из `getHour()`.
  2. **Скорость** — radiogroup `Стоп · 0.5x · 1x · 1.5x · 2x` → `setTimeSpeed`.
  3. **Небо** — radiogroup из 4 вариантов с превью-кружками → `setSky`.
  4. **Качество** — `Авто · Низкое · Среднее · Высокое` → `setQuality`; при «Авто» подпись фактического
     уровня («Авто · среднее»).
  5. **Частицы** — вкл/выкл → `setParticles`.
  6. **Вращение камеры** — вкл/выкл → `setAutoRotate`.
  7. **«Сбросить к настройкам диорамы»**.
- `localStorage['voxel-diorama:settings']` = `{ quality, particles, autoRotate }`; разбор с валидацией,
  мусор → значения по умолчанию. Время, скорость, небо не сохраняются.
- `prefers-reduced-motion: reduce` → автоповорот выкл и скорость 0 по умолчанию (если зритель не включил).
- Пауза внизу останавливает и анимацию, и сутки.
- Dev: `window.__diorama` получает `setHour(h)`, `setSky(kind)`, `setQuality(q)`; `setTime(name)` остаётся
  синонимом `setHour`.
- Компонент `src/lib/components/SettingsPanel.svelte`; логика сохранения — `src/lib/client/settings.ts`.

## 5. Частицы

### API

```ts
particles: [
  smoke({ at: 'house.chimney', rate: 6 }),
  fire({ at: 'campfire.fire', size: 'small' }),
  sparks({ at: 'campfire.fire' }),
  fireflies({ area: [40, 50, 70, 75], count: 40, onlyAtNight: true }),
  snow({ intensity: 0.6 }),
  rain({ intensity: 1, area: [0, 0, 48, 96] }),
  leaves({ area: [0, 0, 30, 80], color: '#d68910' }),
  mist({ area: [0, 30, 96, 46], height: 2 }),
  dust({ area: [40, 40, 60, 60] }),
  smoke({ attachTo: 'boat', offset: [0, 1.2, 0] }),
]
```

- Точечные эмиттеры (`smoke`, `fire`, `sparks`): `at: Point` или `attachTo: id сущности` + `offset`.
- Площадные (`fireflies`, `snow`, `rain`, `leaves`, `mist`, `dust`): `area?: [x0, z0, x1, z1]` (по
  умолчанию вся диорама), высота слоя — по пресету.
- Общие опции: `rate` (частиц/с) или `count`/`intensity` (площадные), `color`, `onlyAtNight`.

| Пресет | Характер | Свечение | Земля |
|---|---|---|---|
| smoke | серые кубы вверх, расширяются, снос «ветром», жизнь 6 с | нет | — |
| fire | оранжево-жёлтые кубы вверх, быстро гаснут, жизнь 0.8 с | да | — |
| sparks | мелкие яркие кубы вверх и в стороны, гравитация, жизнь 1.5 с | да | — |
| fireflies | жёлто-зелёные точки плавают по синусоидам в слое 0.5–3 над землёй, мигают | да | слой над землёй |
| snow | белые кубы падают медленно с качанием | нет | исчезают у земли |
| rain | вытянутые голубые кубы падают быстро | нет | исчезают у земли |
| leaves | кружатся и падают, цвет из опции | нет | исчезают у земли |
| mist | крупные полупрозрачные кубы медленно плывут низко над землёй/водой | нет | слой над землёй |
| dust | мелкие светлые кубы медленно дрейфуют | нет | слой над землёй |

### Рендер (движок)

- Эмиттер = `InstancedMesh` единичного куба, `N = round(rate · lifetime · qualityScale)` инстансов
  (площадные: `count · qualityScale`); атрибут `seed` на инстанс.
- Позиция в вершинном шейдере (TSL) — чистая функция от `(t, i, seed, uniforms)`:
  возраст `age = (t − i / rate) mod lifetime`, `k = age / lifetime`;
  позиция = исток + разброс(seed) + скорость(seed)·age + ½·гравитация·age² + ветер·sin(...);
  размер и цвет — кривые по `k`; исчезновение — масштаб в 0 (без прозрачности, кроме `mist`).
- Падающие пресеты сравнивают y с картой высот (`DataTexture` R32F `sx × sz`, из `buildHeightmap`)
  и не рисуются ниже поверхности.
- Видимость `onlyAtNight` × `night`; `attachTo` — исток (uniform) обновляется по позе экземпляра
  сущности каждый кадр.
- Эталонная функция на TS (`src/engine/particles/math.ts`) повторяет возраст/переработку и размер;
  тесты проверяют её, шейдер строится из тех же констант.
- `qualityScale`: low 0.3, medium 0.6, high 1; `setParticles(false)` скрывает слой.

## 6. Точечный свет

```ts
lights: [
  pointLight({ at: 'campfire.fire', color: '#ff9a3c', intensity: 3, distance: 12, flicker: true }),
  pointLight({ at: 'lamp.light', color: '#ffd27a', onlyAtNight: true }),
  pointLight({ attachTo: 'boat', offset: [0, 1, 0] }),
]
```

- `PointLight` без теней, `distance` по умолчанию 10, `decay` 2, `intensity` по умолчанию 2.
- `flicker`: яркость × `(1 + 0.25 · n(t))`, `n` — детерминированный шум в [−1, 1] (сумма синусов от `t`
  и номера источника).
- `onlyAtNight`: яркость × `night`.
- Лимит: ≤ 8 источников.

## 7. Вода и стекло

- **Вода** (`kind: 'water'`): материал TSL; верхние грани (нормаль y > 0.5) смещаются суммой 2–3
  синусоид от мировых x/z и часов анимации, амплитуда 0.08; нормали пересчитываются аналитически;
  цвет = mix(цвет материала, горизонт неба по часу, френель); прозрачность 0.78. На low — без волн.
- **Стекло** (`kind: 'glass'`): прозрачность 0.35, roughness 0.05, френель по краям, emissive
  проходит (светящееся стекло).

## 8. Пост-обработка, тени, качество

- `RenderPipeline`: `pass(scene, camera, { samples })` → GTAO (high) → bloom → тональная компрессия
  ACES и вывод → FXAA (low). Скриншот рендерится через тот же конвейер.
- Bloom: порог ~0.85 по яркости, сила 0.6 (+0.3 × `night`), радиус 0.4.
- Тени: одна фронтальная тень под границы (≤ 128 по стороне или не high); иначе `CSMShadowNode`
  с 3 каскадами.

| | low | medium | high |
|---|---|---|---|
| DPR (макс.) | 1 | 1.5 | 2 |
| Тень | 1024 | 2048, PCF soft | 2048 + CSM для больших |
| Bloom | нет | 0.5 разрешения | да |
| GTAO | нет | нет | да |
| Частицы | ×0.3 | ×0.6 | ×1 |
| Волны | нет | да | да |
| Сглаживание | FXAA | MSAA ×2 | MSAA ×4 |

- **Авто:** WebGL2-бэкенд или `hardwareConcurrency ≤ 4` → low; `pointer: coarse` (телефон/планшет)
  на WebGPU → medium; иначе high. Чистая функция `pickQuality(caps)`.
- **Понижение:** только в «Авто», после первых 3 с рендера: средний кадр > 33 мс → уровень ниже,
  один раз. Чистая функция `shouldDowngrade(frameTimes)`.
- **`?capture`:** всегда high.
- `setQuality(q)` пересобирает конвейер, тени и плотность частиц, мир не перезагружает.
  `getQuality(): { setting, effective }`.

## 9. Граница SDK ↔ движок

- `src/engine/types.ts`: `SceneConfig.time` (числа), `SceneConfig.sky`, `SceneConfig.quality?`,
  `EmitterSpec`, `LightSpec`, `AtmosphereFactory = (ctx: WorldContext & { entities }) => { emitters, lights }`.
- SDK: пресеты частиц и `pointLight` — фабрики описаний; `createAtmosphereRuntime(diorama, ctx)`
  разрешает якоря и `attachTo` (id сущности → индекс экземпляра), проверяет лимиты, выдаёт
  `EmitterSpec[]` и `LightSpec[]`.
- `mountDiorama(..., { entities, atmosphere?: AtmosphereFactory, fixedTime, quality })`.
- Контроллер: `setHour`, `getHour`, `setTimeSpeed`, `setSky`, `setQuality`, `getQuality`,
  `setParticles`, `setAutoRotate`, `setTime` (синоним), `reloadWorld(url, entities?, atmosphere?)`.
- Движок по-прежнему не импортирует SDK.

## 10. Схема

- `atmosphere.time`: union старой `{ fixed }` и новой `{ start, speed, cycle }` (через `z.custom`/
  `superRefine` с понятными сообщениями), нормализуется в числа.
- `atmosphere.sky` — как в §3.
- `particles` (≤ 32) и `lights` (≤ 8) — разрешены; элементы проверяются как значения фабрик
  (`isEmitterDef`, `isLightDef`) с сообщением «ожидается smoke(…), fire(…)…».
- Неизвестный якорь, неизвестный `attachTo`, превышение частиц (> 20 000 на high) — ошибки
  `createAtmosphereRuntime`, ловятся в `diorama:check`.

## 11. Инструменты, документация

- `diorama:check`: `эмиттеров N · частиц M · света K`; ошибки — по §10; предупреждение при > 80% лимитов.
- Контентный тест — то же для каждой диорамы; регрессионный тест: `quiet-valley` даёт
  `time = { start: 18.5, speed: 0, cycle: 120 }` и `sky = gradient`.
- Skill `new-diorama`: разделы «Время суток и небо», «Частицы и свет»; ревью — снимки в 2–3 часах
  (`__diorama.setHour`), проверка, что дым из трубы, снег исчезает у земли, фонари горят ночью;
  выбор `start` для кадра карточки. CLAUDE.md — краткое упоминание.

## 12. Демо

- **`winter-night` «Зимняя ночь»:** заснеженная деревня (3–4 дома, трубы с дымом), фонари (`lantern`
  + `pointLight onlyAtNight`), костёр (`campfire` + fire + sparks + мерцающий свет) с 2–3 жителями,
  замёрзший пруд (стеклянный лёд), ели, снег, небо `stylized`, `time: { start: 21, speed: 0.5 }`.
- **`river-mill`:** дым из трубы дома, туман над рекой, светлячки над берегом ночью, небо `realistic`,
  `time: { start: 18.5, speed: 1 }`; скриншот пересъёмка.
- **`quiet-valley`** — без изменений.
- Новые префабы: `lantern` (столб + светящийся фонарь, якорь `light`), `campfire` (камни + поленья,
  якорь `fire`); у `house` — якорь `chimney` (над трубой).
